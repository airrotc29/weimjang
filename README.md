# weimjang

위임장 관련 문서 도구 모음입니다.

| 파일 | 내용 |
|---|---|
| `index.html` | **웹 버전** — 브라우저에서 PDF를 넣으면 바로 판독·엑셀 저장 (GitHub Pages용, 파일은 서버로 전송되지 않음) |
| `weimjang_reader.py` | PDF 묶음에서 **제목에 '위임장'이 들어간 페이지만** 골라 판독하고 엑셀로 정리 |
| `power_of_attorney_en.md` | 영문 위임장(Power of Attorney) 템플릿 |
| `manual_overrides.example.json` | 수기 위임장 육안판독 값 입력 예시 |

## 웹 버전 (index.html)

GitHub Pages를 켜면 `https://airrotc29.github.io/weimjang/` 에서 열립니다.

1. Settings → Pages → Build and deployment → Source: **Deploy from a branch**
2. Branch: **main**, 폴더: **/ (root)** → Save
3. 1~2분 뒤 위 주소 접속

무료 계정은 **public 저장소에서만** Pages를 쓸 수 있습니다 (private은 GitHub Pro 이상).

사용법: PDF를 끌어 놓기 → 손글씨·스캔 페이지는 **사람 판독**(판독자 이름 입력 → 판독 시작 → 위임장이면 입력, 아니면 '위임장 아님') → 표에서 값 확인·수정 → 엑셀 내려받기.

### 의결권 집계 (우리 측 · 상대 측)

위임장을 읽은 뒤, 우리 측과 상대 측이 받은 문서를 견주어 우리 측이 확보한 **구분소유자 수와 의결권(면적)** 을 계산합니다.

1. 파일을 넣기 전에 **받은 쪽**(우리 측 / 상대 측)을 고릅니다. 파일을 더 넣으면 기존 결과에 추가되고, 같은 이름의 파일을 다시 넣으면 그 파일만 새로 읽습니다.
2. **구분소유자 명부 올리기**로 엑셀·CSV 명부를 넣습니다. 첫 줄에 `호수`(또는 `호실`), `소유자`, `전유면적` 열이 있어야 하고 `점유자`, `소유자ID` 는 선택입니다. 명부가 없으면 문서에 나온 호수만으로 세고 정족수는 판정하지 않습니다.
3. **정족수**를 고릅니다: 5분의 1 이상(소집 요구, 구분소유자 수만), 과반수, 3분의 2, 4분의 3, 5분의 4 이상.

판정 규칙
- 소유자 문서가 점유자 문서보다 우선합니다 (날짜 무관). 소유자가 철회해 유효한 소유자 문서가 없으면 점유자 문서로 판정합니다.
- 같은 구분 안에서는 가장 나중에 서명한 문서가 유효합니다. 전자서명 완료일시가 있으면 그 시각, 없으면 작성일을 씁니다.
- 제목에 `철회`가 들어간 문서는 철회서로 보고, 같은 쪽에 낸 동의만 없앱니다.
- 같은 시점(시각을 모르면 같은 날)에 상반된 문서가 있으면 `충돌`로 두고 세지 않습니다.
- 한 사람이 여러 호수를 가지면 한 명으로 세고, 그 호수들의 판정이 모두 같을 때만 그 쪽으로 셉니다. 다르면 `혼재`로 둡니다.
- 정족수는 구분소유자 수와 의결권을 모두 넘어야 충족입니다 (5분의 1 소집 요구는 구분소유자 수만).

엑셀에는 `집계`, `호수별 판정` 시트가 추가되고, 첫 시트에 면적과 받은 쪽이 들어갑니다. 받은 쪽·소유자/점유자·동의/철회는 각 줄의 [수정]에서 바꿀 수 있습니다.

읽은 결과는 브라우저를 닫거나 새로 고치면 사라집니다. 작업을 마치면 엑셀로 저장하세요.

그림(스캔) 페이지는 OCR로 먼저 읽습니다.
- 원본증명서·감사추적인증서: 일련번호·서명자·서명일시를 읽어 바로 뒤 위임장에 연결하고 자동 제외
- 투표용지 등 다른 문서: 자동 제외
- 인쇄된 위임장: 해상도를 바꿔 **OCR 2회** → 이름·호수·전화번호가 두 번 모두 같을 때만 자동 판독
- 손글씨(OCR 확신도 낮음)·종류를 알 수 없는 페이지: 사람 판독 (판독자·일시는 엑셀 '사람 판독 기록' 시트에 기록)

오래 걸리면 **[판독 중지]** 로 멈출 수 있고, 그때까지 읽은 결과는 저장할 수 있습니다.
PDF는 브라우저 안에서만 처리되며 어디에도 업로드되지 않습니다.

## weimjang_reader.py

위임장, 의결권행사서, 원본증명서, 감사추적인증서, 별지 명단 등이 섞인 PDF에서 페이지 제목(머리말 제외 첫 줄)에 `위임장`이 있는 페이지만 선별합니다. 본문에만 '위임장'이 언급된 증명서 페이지는 제외됩니다.

### 설치

```bash
pip install -r requirements.txt
```

스캔·사진 페이지를 읽으려면 Tesseract OCR(한국어)도 필요합니다.

```bash
sudo apt-get install -y tesseract-ocr tesseract-ocr-kor poppler-utils
```

### 실행

```bash
python weimjang_reader.py 위임장묶음.pdf -o 위임장_판독결과.xlsx
```

- 폴더를 지정하면 하위 PDF를 모두 처리합니다.
- `--keyword 철회서`: 다른 제목 키워드로 선별
- `--contacts-only`: 이름·호수·전화번호·수임인 시트만 출력
- `--manual manual_overrides.json`: 수기 위임장 값을 사람이 확인한 값으로 덮어쓰기
- `--no-ocr`: 스캔 페이지 OCR 생략

### 엑셀 시트

1. **이름·호수·전화번호**: 이름, 호수, 전화번호, 수임인 (호수 순)
2. **위임장 목록**: 위임인구분, 생년월일, 주소, 작성일, 수임인 정보, 일련번호, 전자서명 완료일시(같은 일련번호의 감사추적인증서에서 연결), 검토필요
3. **페이지 분류**: 모든 페이지의 제목과 선별 여부
4. **요약**: 건수 집계

### 주의

- 수기 위임장은 OCR 정확도가 낮습니다. 엑셀의 페이지 이미지 링크로 원본을 확인하고 `--manual`로 값을 입력하세요.
- 판독 결과는 검토 자료입니다. 대리권 증명(집합건물법 제38조 제2항)의 유효성은 원본으로 확인해야 합니다.
- 결과 엑셀과 원본 PDF에는 개인정보가 들어 있으므로 저장소에 커밋하지 마세요 (`.gitignore`에 제외 설정됨).
